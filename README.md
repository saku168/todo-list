# To-do List

A simple task manager built with **HTML, CSS and vanilla JavaScript**.

## Features
- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Save tasks in the browser with `localStorage`.

## Run locally
1. Clone or download this repository.
2. Open `index.html` in your browser.

No installation or build tools are required.

## Files
- `index.html` — task list structure
- `style.css` — interface styling
- `script.js` — task actions and local storage

## Data storage
Tasks are saved in the current browser on your device. Clearing that browser's site data can remove them.

## What this project practises
DOM manipulation, event handling, arrays, and browser local storage.
